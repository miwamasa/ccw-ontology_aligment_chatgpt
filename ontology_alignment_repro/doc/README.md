## 🎯 目的別ガイド

### 「とにかく動かしたい」
1. [quickstart.md](quickstart.md) を読む
2. コマンドをコピペして実行

### 「テストが失敗して困っている」
1. [testing.md](testing.md) のトラブルシューティングセクション
2. [test_results_sample.md](test_results_sample.md) で正常な出力と比較

### 「プロジェクトを拡張したい」
1. [overview.md](overview.md) でアーキテクチャを理解
2. [testing.md](testing.md) で新しいテストの追加方法を確認
3. `../SPEC.md` で詳細仕様を確認

### 「論文の実験を再現したい」
1. [overview.md](overview.md) で全体像を把握
2. `../SPEC.md` で詳細な再現手順を確認
3. 実際のOAEIデータセットをダウンロード

### 「実際のLLMと統合したい」
1. [overview.md](overview.md) の「今後の拡張」セクション
2. `oracle_clients.py` を編集
3. [testing.md](testing.md) でテスト
